# Bereza Role Play (SA-MP)

## Структура
- `gamemodes/Bereza.pwn` — новий мод (v2.0). Кодування **Windows-1251**, як вимагає SA-MP.
- `old_code/` — старий код (`Bereza.pwn`, `Bereza.amx`, `scriptfiles/acounts`) для архіву.
- `pawno/` — компілятор та інклуди.

## Як запустити
1. Скомпілюйте `gamemodes/Bereza.pwn` через `pawno/pawno.exe` (F5) — з'явиться `Bereza.amx`.
2. У `server.cfg`:
   ```
   gamemode0 Bereza 1
   plugins streamer Pawn.CMD      (на Linux: streamer.so pawncmd.so)
   ```
   MySQL та sscanf новому моду не потрібні.
3. Акаунти зберігаються автоматично у `scriptfiles/bereza.db` (вбудований SQLite).
   Паролі зберігаються як SHA-256 із сіллю.

## Що є в моді
- **Реєстрація** (пароль → повтор пароля → стать → вибір скіну) і **вхід** (3 спроби).
- **Скіни при реєстрації**: 3 бомжі для чоловіків (78, 79, 137) і 3 для жінок (77, 31, 157).
- **Оренда мопеда** Faggio на вокзалі: 15 хв — 99 грн, 30 хв — 179 грн, 60 хв — 299 грн.
- **15 початкових квестів** від бомжа Віталіка (далі він пише SMS):

| # | Квест | Що робити |
|---|-------|-----------|
| 1 | Сніданок чемпіона | зібрати 5 пляшок біля вокзалу |
| 2 | Дзвінка пляшка | здати пляшки (торг із приймальником — 3 варіанти) |
| 3 | Закони вулиці | іспит з RP-правил (RP, DM, MG, PG) |
| 4 | Колеса свободи | орендувати мопед |

| 7 | Золота рибка | риболовля на пірсі (риба, чобіт, чужий гаманець) |
| 8 | Королівське купання | скупатися в океані |
| 9 | Сміттєвий барон | обшукати 4 смітники |

## Команди
`/menu`, `/help`, `/quest`, `/stats`, `/d` (дія, як ALT — для телефонів), `/rent`, `/unrent`,
`/sing`, `/fish`, `/search`, `/me`, `/do`, `/try`, `/b`, `/mypos` (показує координати).

## Налаштування
Координати квестових точок зібрані в таблиці `Points` на початку `Bereza.pwn`.
Якщо якась точка стоїть невдало: станьте в потрібне місце, введіть `/mypos` і вставте координати в таблицю.
