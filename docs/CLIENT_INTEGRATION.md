# Інтеграція Android-клієнта SA-MP у Bereza RP Launcher

Стан на 2026-11-04: **клієнта не інтегровано**. Кнопка «ГРАТИ» вимкнена і показує причину.

## Контракт
`app/src/main/java/ua/bereza/launcher/client/GameClient.kt`

```kotlin
interface GameClient {
    val id: String
    val displayName: String
    val supportedAbis: Set<String>      // arm64-v8a, armeabi-v7a
    val licenseNote: String             // чим підтверджено право використання
    fun availability(context, gameDir): Availability
    fun launch(activity, LaunchParams(host, port, nickname, password, gameDir)): LaunchResult
}
```
Новий клієнт = один клас + рядок у `ClientRegistry.clients`. UI, завантажувач і маніфест змінювати не треба.

## Як клієнт має потрапити в APK
1. **Нативний код (.so) — тільки всередині APK** (`app/src/main/jniLibs/<abi>/` або CMake через NDK).
   - Google Play забороняє завантажувати виконуваний код (.so/.dex) не з Play.
   - Поза Play це технічно можливо, але небезпечно (підміна коду = віддалене виконання на телефоні гравця).
   - Для Android 15+ бібліотеки мають бути вирівняні під сторінки 16 КБ (`-Wl,-z,max-page-size=16384`).
2. **Дані гри (моделі, текстури, карти) — завантажуються за маніфестом** у `Android/data/<пакет>/files/game/`.
3. Клієнт запускається як Activity **всередині лаунчера** (окремий процес `:game`, щоб падіння рушія не вбивало лаунчер).
4. Збірка під дві ABI через `splits { abi { … } }` або universal APK.

## Що потрібно, щоб увімкнути реальний клієнт
| Компонент | Хто правовласник | Що потрібно |
|---|---|---|
| Мультиплеєр-код клієнта | автор клієнта | відкрита ліцензія (MIT/Apache/GPL) з чистим походженням коду **або** письмовий дозвіл |
| Рушій GTA SA (`libGTASA.so`) | Take-Two / Rockstar | ліцензії на поширення немає → вбудовувати не можна |
| Ресурси GTA SA (OBB: моделі, текстури, аудіо) | Take-Two / Rockstar | роздавати з Dropbox не можна; тільки з копії, яку гравець купив |
| Файли Bereza RP (скіни, моди, UI) | ти / автори модів | можна роздавати через маніфест |

## Кандидати (перевірено 2026-11-04)
- **SAMP Mobile / SA-MP Android (лінійка v69, kuzia15/SAMP-Mobile, game.samp.ru тощо)** — команда open.mp заявляє, що код походить із вкрадених вихідників SA-MP. Використовувати не можна.
- **SA-MP-Android/App** — лише бінарні релізи, без ліцензії і без коду; потребує libGTASA.so. Можна лише попросити дозвіл, але проблема рушія лишається.
- **SampDroid (xykal/sampdroid)** — MIT, власний рендерер GLES, не використовує libGTASA.so, читає GTA-дані гравця. Ранній стан (спавн на живому сервері ще не підтверджено). Походження протокольного коду треба перевірити перед використанням. Найперспективніший легальний варіант.
- **open.mp mobile** — офіційного клієнта немає.
